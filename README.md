## 工程说明

工程脚本分为两类：

1. **通用技术工具**：DAT 目录解析、资源编解码、文本槽位检查、封包与一致性验证。
2. **语言包工作流脚本**：读取本地私有的翻译表并生成构建产物。翻译数据未收录，因此归档仓库本身不能重建可运行的汉化版本。

工具主要依赖 Node.js、Python 3；部分图像工具需要 Pillow，`ZPGDI_proxy.c` 的构建需要 32 位 MinGW。每个工具的命令行参数可通过 `--help` 查看。

## 验证方式

本归档只做源码级语法检查，不读取或写入游戏文件：

```powershell
Get-ChildItem .\tools\*.py | ForEach-Object { python -m py_compile $_.FullName }
Get-ChildItem .\tools\*.js | ForEach-Object { node --check $_.FullName }
```
